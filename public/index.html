How to apply this in HubSpot

Select the leads, copy the emails, then in HubSpot open Contacts, add a filter on Email, choose is any of, paste, select all in the resulting view, and use Assign. Record ID does not offer is any of, which is why this copies emails.

Semicolon separated is the default because that is what the filter box accepts most reliably. Use One per line if your version of the box prefers line breaks, and Copy as CSV if you would rather move them through an Import that updates existing contacts matched on email.

This desk never writes to HubSpot. It has no write endpoint and its token needs no write scope. The owner changes only when you make it change, in HubSpot, where there is an audit trail and an undo.

Lead Desk. Reads HubSpot every ten minutes, call records and property history every hour. Value is the stage's chance of paying this month, discounted by how many calls the lead has already taken in that stage, times the creator's average first payment. Use it to rank, not to forecast.
